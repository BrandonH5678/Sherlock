### IMP_004: Priority Change Hysteresis

**Category:** Priority Stability
**File Modified:** `/home/johnny5/Sherlock/src/llm_targeting_officer.py`
**Lines Changed:** 594-605

**Change:**
```python
# BEFORE
if assessment.recommended_priority != target['priority']:
    self._update_target_priority(...)
    priorities_updated += 1

# AFTER
priority_delta = abs(assessment.recommended_priority - target['priority'])
if assessment.recommended_priority != target['priority'] and priority_delta >= 2:
    self._update_target_priority(...)
    priorities_updated += 1
elif assessment.recommended_priority != target['priority'] and priority_delta == 1:
    logger.debug(f"Skipping 1-level priority change for {target['name']} (hysteresis)")
```

**Expected Impact:**
- Reduce priority updates by ~30% (eliminate oscillation)
- Require 2+ level change (e.g., 3→5 or 4→2) to trigger update
- Stabilize priorities for targets with marginal differences

**Validation:** PASSED (syntax check successful)

### IMP_005: Research Question Validation

**Category:** Research Quality
**File Modified:** `/home/johnny5/Sherlock/src/llm_targeting_officer.py`
**Lines Changed:** 369-402

**Change:**
```python
# BEFORE
for q_data in questions_data[:max_questions]:
    questions.append(ResearchQuestion(
        question=q_data.get('question', 'No question provided'),
        ...
    ))

# AFTER
for q_data in questions_data[:max_questions]:
    if not isinstance(q_data, dict):
        continue

    question_text = q_data.get('question', '').strip()
    if not question_text or question_text == 'No question provided':
        logger.warning(f"Skipping invalid question: {q_data}")
        continue

    questions.append(ResearchQuestion(
        question=question_text,
        ...
    ))

if not questions:
    logger.warning(f"No valid questions generated from LLM response")
```

**Expected Impact:**
- Filter out invalid/empty questions before job creation
- Log warnings when question generation fails
- Prevent creation of unusable jobs
- Enable diagnosis of LLM prompt issues
